## English

**Caliper** (2026) — Angular app that consumes the PageSpeed Insights API and compares Core Web Vitals across several URLs side by side. Open source, MIT.

- Angular 21 standalone and zoneless, strict TypeScript with strictTemplates, 3 lazy routes and 4 hand written SVG components, no charting library.
- 48 tests running on both runners (Vitest and Karma with Jasmine) at 94% statement coverage, covering retry with backoff, switchMap cancellation and the serial ordering of the compare queue.
- Lighthouse on the production build: 96 performance and 100 accessibility on desktop, 61 performance on mobile, with the Angular Material cost documented as the bottleneck.
